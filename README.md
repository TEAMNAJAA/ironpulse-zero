# IronPulse Zero

ตรวจจับ **ความไม่สมดุลของมวลหมุน** จากวิดีโอกล้องมือถือ โดยไม่ต้องแตะเครื่องจักร
กล้อง iPhone ที่ 240 fps → optical flow ระดับซับพิกเซล → โมเดลตรวจจับสิ่งผิดปกติที่เรียนจากเครื่องปกติเท่านั้น

**หน้าแสดงผล → https://teamnajaa.github.io/ironpulse-zero/**

> ⚠️ **ขอบเขต** ระบบนี้ตรวจได้เฉพาะความไม่สมดุลของมวลหมุนอย่างเดียว
> ชุดข้อมูลไม่มีฐานหลวม การอุดตัน หรือการเสียดสี จึงไม่ประเมินและไม่รายงานชนิดเหล่านั้นในทุกกรณี

## รันเว็บแอป

**วิธีที่ง่ายที่สุดบน Windows** ดับเบิลคลิก `เปิดเว็บแอป.bat` ที่โฟลเดอร์หลัก
สคริปต์จะติดตั้งไลบรารีให้ถ้ายังไม่ครบ นำเข้า baseline ที่เตรียมไว้ แล้วเปิดเบราว์เซอร์ให้เอง
macOS หรือ Linux ใช้ `./open-webapp.sh`

**นำขึ้นเน็ตด้วย Render** ดู [DEPLOY_RENDER.md](DEPLOY_RENDER.md) — มี `Dockerfile` และ `render.yaml` เตรียมไว้แล้ว

**หรือรันเองทีละขั้น**

```bash
git clone https://github.com/TEAMNAJAA/ironpulse-zero.git
cd ironpulse-zero/ironpulse
pip install -r requirements.txt
python web/baseline_seed.py import
python run.py
```

เปิดเบราว์เซอร์ให้อัตโนมัติที่ `http://127.0.0.1:8765/`
**ไม่ต้องต่ออินเทอร์เน็ตขณะใช้งาน** ไม่มี CDN ไม่มี build step ไม่มี npm ไม่มี Docker

`web/baseline_seed.py import` นำเข้า baseline ที่ฝึกไว้แล้วจากคลิปปกติ 38 คลิป (ไฟล์ 26 KB ใน repo)
จึงใช้งานได้ทันทีโดยไม่ต้องมีไฟล์วิดีโอ **คะแนนที่ได้ตรงกับตอนฝึกทุกหลัก**

⚠️ คลิปวิดีโอไม่ได้อยู่ใน repo เพราะไฟล์ละราว 100 MB ปุ่มลัดคลิปสาธิตจึงไม่ขึ้น
ให้ลากไฟล์วิดีโอของคุณมาวางในหน้าเว็บ หรือวางไฟล์ไว้ใน `ironpulse/data/demo/` แล้วรีเฟรช

## สร้างผลและรูปทั้งหมดใหม่ โดยไม่ต้องมีไฟล์วิดีโอ

คลิปวิดีโอไม่ได้อยู่ใน repo เพราะไฟล์ละราว 100 MB (รวม 6 GB)


## หลักการที่ยึดตลอดโครงงาน

- โมเดลเรียนจากคลิปเครื่องปกติเท่านั้น ไม่เคยเห็นคลิปผิดปกติตอนฝึก
- เกณฑ์ตัดสินตั้งจากคะแนนของคลิปปกติในชุดฝึกเท่านั้น และไม่ปรับหลังเห็นผลของคลิปผิดปกติ
- แบ่งข้อมูลตามรอบการถ่าย ไม่ใช่ตามคลิป เพื่อไม่ให้โมเดลจำการตั้งกล้องแทนที่จะจำสภาวะเครื่อง
- ไม่ทำซ้ำและไม่สังเคราะห์คลิปเพื่อเพิ่มจำนวนตัวอย่าง
- ตัวเลขจากงานวิจัยบนชุดข้อมูลสาธารณะไม่ถูกนำมาปนกับผลของวิดีโอ เพราะไม่ได้ผ่านกล้อง
- ทุกพารามิเตอร์อยู่ใน `config.yaml` และมีที่มาวัดจริง ไม่มีค่าเดา ดู `ironpulse/HANDOVER_PARAMS.md`
- ผลที่ออกมาไม่ดีถูกรายงานตามจริงพร้อมคำอธิบายว่าเพราะอะไร ไม่ซ่อน
